    #001 · featured

    Ticket management dashboard

    Problem: tickets split between Jira and ServiceNow, tracked by hand.

    Solution: Node.js/Express with the Jira API plus a script that normalizes ServiceNow, all in one view with Chart.js.

    Result: volume, status and SLA per client without manual spreadsheets.

    Node.js · Express · Jira API · ServiceNow · Chart.js · SheetJS

    Internal project · real screenshot with sensitive data hidden

    #002 · new

    Management app for a tango school

    Problem: students, bookings, payments and class packs spread across spreadsheets and messages; nobody knew who had paid or how many classes each student had left.

    Solution: a bilingual (Spanish/English) web and mobile app with a login for each teacher: attendance that deducts from the pack and flags the last class, pending payments, a calendar that follows summer and winter time, events, and birthday greetings via WhatsApp.

    Result: students, packs and payments tracked in one place, on every teacher’s phone, with the data always online.

    JavaScript · HTML · CSS · Google Apps Script · Google Sheets · PWA

    Real client: Tango Culture, Adelaide (Australia) · screenshot with fictitious data
