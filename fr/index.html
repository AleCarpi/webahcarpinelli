    #001 · à la une

    Tableau de bord de gestion des tickets

    Problème : des tickets répartis entre Jira et ServiceNow, suivis à la main.

    Solution : Node.js/Express avec l'API Jira et un script qui normalise ServiceNow, le tout dans une vue avec Chart.js.

    Résultat : volume, statut et SLA par client, sans tableurs manuels.

    Node.js · Express · Jira API · ServiceNow · Chart.js · SheetJS

    Projet interne · capture réelle, données sensibles masquées

    #002 · nouveau

    Application de gestion pour une école de tango

    Problème : élèves, réservations, paiements et forfaits de cours dispersés entre tableurs et messages ; personne ne savait qui avait payé ni combien de cours il restait à chacun.

    Solution : une application web et mobile, en espagnol et en anglais, avec une connexion pour chaque professeur : présences qui décomptent du forfait et signalent le dernier cours, paiements en attente, calendrier suivant l’heure d’été et d’hiver, événements et vœux d’anniversaire par WhatsApp.

    Résultat : le suivi des élèves, des forfaits et des paiements au même endroit, sur le téléphone de chaque professeur, avec des données toujours en ligne.

    JavaScript · HTML · CSS · Google Apps Script · Google Sheets · PWA

    Client réel : Tango Culture, Adélaïde (Australie) · capture avec des données fictives

    Voir le code sur GitHub

    #003

    Automatisation et gestion avec l'IA

    Problème

    Solution

    Marketplace B2B et SaaS

    Problème
